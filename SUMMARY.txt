La integración entre el Frontend (Next.js) y Backend (Flask) está completamente 
lista. Los usuarios pueden:

✅ Todo validado contra base de datos Supabase

────────────
  Terminal 1: cd api && python -m venv venv && venv\Scripts\activate && python -m flask run
  Terminal 2: npm run dev
  Navegador:  http://localhost:3000

📊 FLUJO DE COMUNICACIÓN

  ┌─────────────┐                  ┌──────────────┐
  │   FRONTEND  │                  │   BACKEND    │
  │  (3000)     │                  │   (5000)     │
  └─────────────┘                  └──────────────┘
        │                                 │
        ├──── POST /auth/login ─────────→ │
        │   {groupCode, studentCode}      │
        │                                 │
        │                   ┌─ Valida en Supabase
        │                   │
        │ ← {token, user} ───┘
        │
        ├─ localStorage.setItem("eco_token", token)
        │
        ├──── GET /auth/me ────────────→ │
        │   Authorization: Bearer <token> │
        │                                 │
        │                   ┌─ Valida JWT
        │                   │
        │ ← {user} ─────────┘
        │
        ├──── POST /api/chat ────────→ │
        │   message, sesion_id          │
        │   Authorization: Bearer token │
        │                               │
        │                ┌─ Procesa con OpenAI
        │                │
        │ ← {message, thread_id} ───┘
